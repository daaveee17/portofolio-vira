## 🚀 Cara Menjalankan

### Cara 1: Langsung Buka di Browser
Cukup klik ganda file `index.html` di File Explorer, atau klik kanan dan pilih **Open with Google Chrome / Microsoft Edge**.

### Cara 2: Menjalankan Local Web Server
Buka terminal (PowerShell atau Command Prompt) di folder ini dan jalankan salah satu perintah:
```bash
# Menggunakan Node.js npx serve
npx serve .

# Atau menggunakan Python jika terinstal
python -m http.server 8080
```
Lalu buka browser di `http://localhost:3000` atau `http://localhost:8080`.
